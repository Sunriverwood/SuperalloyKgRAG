# 不同类型图谱的三元组提取方式详解

本文档详细说明了 SuperalloyKgRAG 系统中四种不同类型图谱的三元组（实体-关系-实体）提取方法。

------

## 📊 概览

系统通过 `enrich_extraction.py` 模块协调四种图谱的提取和合并：

| 图谱类型       | 源文件                      | 提取模块               | 输出文件                       | 数据来源    |
| -------------- | --------------------------- | ---------------------- | ------------------------------ | ----------- |
| **纯文本图谱** | chunks/text_units.jsonl     | extraction_qwen.py     | extracted_graph.jsonl          | PDF正文分块 |
| **摘要图谱**   | chunks/abstract_units.jsonl | abstract_extraction.py | extracted_abstract_graph.jsonl | Excel摘要列 |
| **图片图谱**   | processed_jsons/*.json      | image_extraction.py    | extracted_image_graph.jsonl    | 图表/照片   |
| **表格图谱**   | processed_jsons/*.json      | table_extraction.py    | extracted_table_graph.jsonl    | 表格数据    |

最终合并为：`enriched_graph.jsonl`

------

## 1️⃣ 纯文本图谱提取 (Text Graph)

### 📝 数据流程

```
PDF文档 → vlm_pdf_parser → processed_jsons/*.json 
→ DocumentLoader分块 → text_units.jsonl 
→ extraction_qwen.py → extracted_graph.jsonl
```

### 🔍 提取方法

#### **输入格式**

```json
{
  "id": "chunk-abc123",
  "document_id": "doc-xyz789",
  "text": "Inconel 718 is a nickel-based superalloy with excellent high-temperature strength...",
  "metadata": {
    "source_filename": "paper1.json",
    "pages": [5, 6]
  }
}
```

#### **Prompt 策略** (`text_to_graph.md`)

- **角色**: KG Extractor

- 核心原则

  :

  - 只从文本中提取，不做外部推理
  - 实体ID用 `e-N`，关系ID用 `r-N`
  - 输出严格的JSON格式

#### **实体提取规则**

```json
{
  "id": "e-1",
  "name": "Inconel 718",  // 具体实体名（不用泛指）
  "type": "Material",      // 技术类别
  "description": "A nickel-based superalloy with high-temperature strength...",
  "attributes": {
    "strength": "1250 MPa",
    "temperature": "650°C"
  }
}
```

#### **关系提取规则**

```json
{
  "id": "r-1",
  "source": "e-1",
  "target": "e-2",
  "relationship": "HAS_PROPERTY",  // 大写简洁动词
  "description": "Inconel 718 exhibits high strength at elevated temperatures",
  "weight": 5,  // 1-5（5=最明确/重要）
  "source_sentence": "Inconel 718 exhibits a tensile strength of 1250 MPa at 650°C"
}
```

#### **技术实现**

- **API**: 阿里云百炼 (OpenAI兼容接口)
- **模型**: qwen-plus/qwen-turbo
- **批处理**: 使用 Batch API 提高效率
- **响应格式**: `response_format: {"type": "json_object"}`

## 2️⃣ 摘要图谱提取 (Abstract Graph)

### 📝 数据流程

```
Excel文件 → abstract_extraction.py读取摘要列 
→ abstract_units.jsonl → Batch API 
→ extracted_abstract_graph.jsonl
```

### 🔍 提取方法

#### **输入格式**

从Excel读取论文元数据：

```python
{
  'title': '论文标题',
  'abstract': '摘要文本...',
  'journal': '期刊名',
  'year': '2023',
  'author': '作者',
  'doi': '10.xxxx/xxxxx'
}
```

生成的 abstract_units.jsonl：

```json
{
  "id": "chunk-md5hash",
  "document_id": "doc-md5hash",
  "text": "摘要全文...",
  "metadata": {
    "source_filename": "论文标题",
    "type": "abstract",
    "journal": "Journal Name",
    "year": "2023"
  }
}
```

#### **Prompt 策略**

- 使用与纯文本相同的 `text_to_graph.md`
- 但摘要更聚焦于：
  - **研究材料**（如 Alloy 706）
  - **核心发现**（如 γ'' 相析出）
  - **关键性能**（如强度、寿命）
  - **研究方法**（如时效处理）

#### **特点**

- 摘要信息密度高，提取的实体和关系更宏观
- 适合构建**全局知识骨架**
- 包含论文元数据（期刊、年份、DOI）便于溯源

## 3️⃣ 图片图谱提取 (Image Graph)

### 📝 数据流程

```
PDF → VLM解析 → processed_jsons/*.json (含图片描述)
→ image_extraction.py → extracted_image_graph.jsonl
```

### 🔍 提取方法

图片分为三种类型，每种使用不同的Prompt：

### **3.1 图表 (Chart)** - `chart_to_graph.md`

#### **输入上下文**

```python
Block ID: fig-1
Image Type: chart
Caption: Fig. 2. Yield strength vs. temperature for Inconel 718
Title: Mechanical Properties
X-axis: Temperature (°C)
Y-axis: Yield Strength (MPa)
Legend: ['As-cast', 'Heat-treated']
Trend Description: Strength decreases linearly from 1200 MPa at 20°C to 800 MPa at 700°C
Data Points: [{"temp": 20, "strength": 1200}, {"temp": 400, "strength": 1000}, ...]
```

#### **实体提取策略**

- **材料实体**: 从图例和标题提取（Inconel 718）
- **属性实体**: 轴标签对应的测量参数（Yield Strength, Temperature）
- **趋势实体**: 显著的模式（如"线性下降"）
- **条件实体**: 样本状态（As-cast, Heat-treated）

```json
{
  "id": "e-1",
  "name": "Yield Strength",
  "type": "PROPERTY",
  "description": "Decreases from 1200 MPa at 20°C to 800 MPa at 700°C for Inconel 718",
  "attributes": {
    "source_chart": "fig-1",
    "unit": "MPa",
    "value_range": "800-1200",
    "chart_role": "y_axis"
  }
}
```

#### **关系提取策略**

- 使用特殊关系类型捕获趋势：
  - `DECREASES_WITH`: 强度随温度降低
  - `INCREASES_WITH`: 正相关
  - `CORRELATES_WITH`: 相关性
  - `EXHIBITS`: 材料展现某属性

```json
{
  "id": "r-1",
  "source": "e-YieldStrength",
  "target": "e-Temperature",
  "relationship": "DECREASES_WITH",
  "description": "Yield strength shows linear decrease with increasing temperature",
  "source_sentence": "Strength decreases linearly from 1200 MPa at 20°C to 800 MPa at 700°C",
  "attributes": {
    "trend_type": "decreasing",
    "magnitude": "-400 MPa over 680°C"
  }
}
```

### **3.2 示意图 (Schematic)** - `schematic_to_graph.md`

#### **输入上下文**

```python
Block ID: fig-3
Image Type: schematic
Caption: Fig. 5. Microstructure showing γ' and γ'' precipitates
Description: The schematic illustrates the distribution of γ' cubic precipitates (size ~50nm) within γ matrix...
OCR Text: γ' phase, γ'' phase, grain boundary
```

#### **实体提取策略**

- **相/微观结构**: γ' 相, γ'' 相, 晶界
- **形貌特征**: 立方形, 球形, 针状
- **尺寸信息**: ~50nm

#### **关系类型**

- `DISTRIBUTED_IN`: γ' 分布在基体中
- `SURROUNDED_BY`: 析出相被包围
- `ADJACENT_TO`: 空间邻近关系

### **3.3 照片/显微图 (Photograph)** - `photograph_to_graph.md`

#### **输入上下文**

```python
Block ID: fig-7
Image Type: photograph
Caption: SEM image of fractured surface showing intergranular cracking
Description: The SEM image at 5000x magnification shows intergranular cracks propagating along grain boundaries. Fine γ'' precipitates (10-20nm) are visible within grains...
```

#### **实体提取策略**

```json
{
  "id": "e-crack",
  "name": "Intergranular Crack",
  "type": "DEFECT",
  "description": "Crack propagating along grain boundaries observed in SEM at 5000x",
  "attributes": {
    "source_photograph": "fig-7",
    "imaging_technique": "SEM",
    "magnification": "5000x",
    "morphology": "irregular path",
    "distribution": "along grain boundaries"
  }
}
```

#### **关系类型**

- `OBSERVED_IN`: 裂纹在材料中观察到
- `PROPAGATES_ALONG`: 裂纹沿着晶界扩展
- `EXHIBITS`: 材料展现某种缺陷

## 4️⃣ 表格图谱提取 (Table Graph)

### 📝 数据流程

```
PDF → VLM解析 → processed_jsons/*.json (含表格JSON)
→ table_extraction.py → extracted_table_graph.jsonl
```

### 🔍 提取方法

#### **输入上下文** (`table_to_graph.md`)

```python
Caption: Table 2. Chemical composition and mechanical properties of superalloys
Summary: Comparison of three nickel-based superalloys
Data:
[
  ["Alloy", "Ni (%)", "Cr (%)", "Fe (%)", "YS (MPa)", "UTS (MPa)"],
  ["Inconel 718", "52.5", "19.0", "18.5", "1000", "1300"],
  ["Alloy 625", "61.0", "21.5", "5.0", "450", "900"],
  ["Waspaloy", "58.0", "19.5", "0.5", "850", "1100"]
]
```

#### **提取策略**

**步骤1: 主体列识别**

- 识别"主体"列（如 Alloy, Material Name, Sample ID）
- 每一行的主体成为一个核心实体

**步骤2: 描述富化（关键！）**

- ⚠️ **CRITICAL**: 实体描述必须整合整行所有数据点
- ❌ **错误**: "An alloy."
- ✅ **正确**: "Inconel 718 is a Nickel-based superalloy containing 52.5% Ni, 19.0% Cr, and 18.5% Fe, with yield strength of 1000 MPa and ultimate tensile strength of 1300 MPa."

**目的**: 让描述向量化后能被检索到！

#### **实体提取示例**

```json
{
  "id": "e-1",
  "name": "Inconel 718",
  "type": "Material",
  "description": "Nickel-based superalloy containing 52.5% Ni, 19.0% Cr, 18.5% Fe with yield strength 1000 MPa and UTS 1300 MPa",
  "attributes": {
    "source_table": "table-2",
    "Ni": "52.5%",
    "Cr": "19.0%",
    "Fe": "18.5%",
    "YS": "1000 MPa",
    "UTS": "1300 MPa"
  }
}
```

#### **关系提取示例**

```json
{
  "id": "r-1",
  "source": "e-Inconel718",
  "target": "e-YieldStrength1000MPa",
  "relationship": "HAS_PROPERTY",
  "description": "Inconel 718 has a yield strength of 1000 MPa",
  "source_sentence": "Table shows Inconel 718 YS value is 1000 MPa"
}
```

#### **缩写解析**

Prompt要求自动解析常见缩写：

- YS → Yield Strength
- UTS → Ultimate Tensile Strength
- HV → Vickers Hardness
- σ → Stress

## 🔧 统一技术架构

### **Batch API 流程** (所有图谱通用)

```
1. 准备请求 → JSONL (custom_id + messages)
2. 上传文件 → client.files.create(purpose="batch")
3. 创建作业 → client.batches.create(input_file_id, endpoint="/v1/chat/completions")
4. 轮询状态 → client.batches.retrieve(batch_id)
5. 下载结果 → client.files.content(output_file_id)
6. 解析输出 → 提取JSON格式的graph
```

### **请求格式**

```json
{
  "custom_id": "chunk-abc123",
  "method": "POST",
  "url": "/v1/chat/completions",
  "body": {
    "model": "qwen-plus",
    "messages": [
      {"role": "system", "content": "<prompt_template>"},
      {"role": "user", "content": "<实际内容>"}
    ],
    "temperature": 0.1,
    "top_p": 0.9,
    "response_format": {"type": "json_object"}
  }
}
```

### **输出格式** (统一)

```json
{
  "id": "chunk-abc123",
  "document_id": "doc-xyz789",
  "text": "原始文本/上下文",
  "metadata": {...},
  "graph": {
    "entities": [...],
    "relationships": [...],
    "source_type": "text|abstract|image|table"  // 由enrich_extraction添加
  }
}
```

## ✅ 验证与修复

`enrich_extraction.py` 在合并时会验证和修复常见错误：

### **实体格式错误修复**

1. **"nameXXX: " 类型错误**: 字段名包含了实际名称
2. **重复字段**: 同时有 "e-6" 和 "id": "e-6"
3. **缺失必需字段**: 自动补充 name, type, description
4. **类型推断**: 根据名称推断实体类型
5. **描述生成**: 为缺失描述的实体生成默认描述

### **修复统计示例**

```

  已修复实体数: 87
  
  错误类型分布:
    - name_merged_with_description: 34
    - type_inferred: 28
    - description_generated: 15
    - missing_id_field: 10
```

## 📊 总结对比

| 特性         | 纯文本     | 摘要     | 图表      | 表格       |
| ------------ | ---------- | -------- | --------- | ---------- |
| **信息粒度** | 细节丰富   | 宏观概括 | 趋势/视觉 | 结构化数值 |
| **实体类型** | 全面       | 研究焦点 | 测量参数  | 样本属性   |
| **关系密度** | 高         | 中       | 趋势关系  | 属性关系   |
| **数值精度** | 低-中      | 低       | 高        | 最高       |
| **最佳用途** | 理解上下文 | 快速定位 | 定量分析  | 对比筛选   |

### **协同效应**

- **文本** 提供背景和解释
- **摘要** 建立全局骨架
- **图表** 揭示定量趋势
- **表格** 提供精确数值

通过 `enriched_graph.jsonl` 将四种图谱合并，形成**多模态知识图谱**，支持更全面的检索和推理！
