# Global Query 工作流程图

```
┌─────────────────────────────────────────────────────────────────────────┐
│                          用户查询: "钛合金的性质？"                        │
└─────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ 步骤1: 向量化查询                                                         │
│ _embed_query(query) → [0.123, 0.456, ..., 0.789] (256维向量)            │
└─────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ 步骤2: 检索相关社区                                                       │
│ _build_context_chunks(query_vector)                                    │
│                                                                         │
│ LanceDB 向量搜索 → Top 3 社区                                            │
│ ┌──────────────────────────────────────────────┐                       │
│ │ Community 5                                  │                       │
│ │ - id: "community_5"                          │                       │
│ │ - vector: [0.234, 0.567, ...]                │                       │
│ │ - payload_report_json: "{...}"  ◄───────────┼── ✅ 同时获取          │
│ │ - payload_map_json: "{...}"     ◄───────────┼── ✅ 同时获取          │
│ └──────────────────────────────────────────────┘                       │
│ ┌──────────────────────────────────────────────┐                       │
│ │ Community 7 (同上)                            │                       │
│ └──────────────────────────────────────────────┘                       │
│ ┌──────────────────────────────────────────────┐                       │
│ │ Community 11 (同上)                           │                       │
│ └──────────────────────────────────────────────┘                       │
└─────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ 步骤3: Map 阶段 - 并行处理每个社区                                         │
│ _map_single_chunk(query, context_chunk) × 3                            │
└─────────────────────────────────────────────────────────────────────────┘
        │                           │                           │
        ▼                           ▼                           ▼
┌──────────────────┐    ┌──────────────────┐    ┌──────────────────┐
│  Community 5     │    │  Community 7     │    │  Community 11    │
└──────────────────┘    └──────────────────┘    └──────────────────┘
        │                           │                           │
        └───────────────────────────┴───────────────────────────┘
                                    │
                    ┌───────────────▼───────────────┐
                    │  每个社区都执行以下步骤：       │
                    └───────────────┬───────────────┘
                                    │
                    ┌───────────────▼───────────────────────────────┐
                    │ 3.1 提取 payload 数据                         │
                    │ payload_report_json = context_chunk.get(...)  │
                    │ payload_map_json = context_chunk.get(...)     │
                    └───────────────┬───────────────────────────────┘
                                    │
                    ┌───────────────▼───────────────────────────────┐
                    │ 3.2 解析 JSON                                 │
                    │ report = json.loads(payload_report_json)      │
                    │ id_map = json.loads(payload_map_json)         │
                    │                                               │
                    │ report = {                                    │
                    │   "summary": "...E1...E2...R1...",            │
                    │   "findings": [...]                           │
                    │ }                                             │
                    │                                               │
                    │ id_map = {                                    │
                    │   "E1": "chunk-abc123-e-4",                   │
                    │   "E2": "chunk-abc123-e-5",                   │
                    │   "R1": "chunk-abc123-r-2"                    │
                    │ }                                             │
                    └───────────────┬───────────────────────────────┘
                                    │
                    ┌───────────────▼───────────────────────────────┐
                    │ 3.3 ✅ ID 转换                                 │
                    │ _convert_local_ids_to_chunk_ids(report, map)  │
                    │                                               │
                    │ 转换前:                                        │
                    │ "...温度T₂是组分A的熔化温度                    │
                    │  [Data: Entities (E1, E2); Relationships (R1)]"│
                    │                                               │
                    │ 转换后:                                        │
                    │ "...温度T₂是组分A的熔化温度                    │
                    │  [Data: Entities (chunk-abc123-e-4,           │
                    │   chunk-abc123-e-5); Relationships            │
                    │   (chunk-abc123-r-2)]"                        │
                    └───────────────┬───────────────────────────────┘
                                    │
                    ┌───────────────▼───────────────────────────────┐
                    │ 3.4 构建 context_data                         │
                    │ {                                             │
                    │   "community_id": "community_5",              │
                    │   "report": <转换后的report>                  │
                    │ }                                             │
                    └───────────────┬───────────────────────────────┘
                                    │
                    ┌───────────────▼───────────────────────────────┐
                    │ 3.5 发送给 LLM                                │
                    │ Prompt: global_map.md                         │
                    │ + context_data                                │
                    │ + query                                       │
                    └───────────────┬───────────────────────────────┘
                                    │
                    ┌───────────────▼───────────────────────────────┐
                    │ 3.6 LLM 返回提取的关键点                       │
                    │ {                                             │
                    │   "results": [                                │
                    │     {                                         │
                    │       "answer": "温度T₂是组分A的熔化温度       │
                    │         [cite: chunk-abc123-e-4,              │
                    │          chunk-abc123-e-5, chunk-abc123-r-2]",│
                    │       "score": 8                              │
                    │     }                                         │
                    │   ]                                           │
                    │ }                                             │
                    └───────────────────────────────────────────────┘
                                    │
        ┌───────────────────────────┴───────────────────────────┐
        │     聚合所有社区的关键点                                │
        └───────────────────────────┬───────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ 步骤4: Reduce 阶段                                                        │
│ _reduce_response(query, map_results)                                   │
│                                                                         │
│ 4.1 过滤和排序 (score > 0，按分数降序)                                   │
│                                                                         │
│ 4.2 格式化成分析师报告                                                   │
│ - [得分:8] 温度T₂是组分A的熔化温度 [cite: chunk-abc123-e-4, ...]         │
│ - [得分:7] 钛合金具有良好的耐腐蚀性 [cite: chunk-def456-e-3, ...]        │
│ - ...                                                                   │
│                                                                         │
│ 4.3 发送给 LLM                                                          │
│ Prompt: global_reduce.md                                               │
│ + report_data (分析师报告)                                              │
│ + query                                                                │
│ + constraints (是否允许通用知识)                                         │
│                                                                         │
│ 4.4 LLM 返回最终答案                                                     │
└─────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ 最终答案 (带引用)                                                         │
│                                                                         │
│ 钛合金是一种重要的结构材料，具有以下性质：                                 │
│                                                                         │
│ 1. **相变温度**: 纯钛的β转变温度约为882°C，即α相到β相的转变温度          │
│    [cite: chunk-abc123-e-4, chunk-abc123-e-5, chunk-abc123-r-2]        │
│                                                                         │
│ 2. **耐腐蚀性**: 钛合金在海水和酸性环境中表现出优异的耐腐蚀性能           │
│    [cite: chunk-def456-e-3, chunk-def456-r-1]                          │
│                                                                         │

关键创新点：

✅ 1. 查询时同时获取 payload_report_json 和 payload_map_json
    → LanceDB 检索自动返回所有字段

✅ 2. 将局部 ID 转换为 chunk ID
    → _convert_local_ids_to_chunk_ids() 方法
    → E1 → chunk-abc123-e-4

✅ 3. 传递重构后的文本给 LLM
    → context_data 包含转换后的 report
    → LLM 看到的是真实的 chunk ID

✅ 4. 更新 Prompt 支持引用
    → global_map.md: 提取并转换引用
    → global_reduce.md: 保留并传递引用
```
