# SuperalloyKgRAG 项目架构说明

## 📋 项目概述

SuperalloyKgRAG 是一个基于知识图谱的增强检索生成（Knowledge Graph RAG）系统，专注于超合金领域的知识抽取、存储和问答。

## 🔄 核心流程说明

### 1. 索引流水线 (run_indexing.py)

**完整流程**: PDF → JSON → 文本块 → 三元组 → 知识图谱 → 向量库

```
步骤1: OCR解析
  输入: data/raw_pdfs/*.pdf
  输出: data/processed_jsons/*.json
  功能: VLM模型解析PDF为结构化JSON

步骤2: 文本分块
  输入: data/processed_jsons/*.json
  输出: data/chunks/text_units.jsonl
  功能: 将文档切分为可处理的文本单元

步骤3: 三元组提取
  输入: data/chunks/text_units.jsonl
  输出: data/graphs/extracted/extracted_graph.jsonl
  功能: LLM从文本中提取实体和关系

步骤4: 图谱构建
  输入: data/graphs/extracted/extracted_graph.jsonl
  输出: data/graphs/final_graph.json
        data/reports/community_summaries.jsonl
  功能: 实体消歧、社区发现、社区摘要生成

步骤5: 向量化存储
  输入: final_graph.json + community_summaries.jsonl
  输出: data/embeddings/embedding.db/
  功能: 将实体、关系、社区嵌入向量数据库
```

### 2. 查询路由流程 (router_qwen.py)

**查询分类**: 使用CoT(Chain of Thought)技术智能分类查询类型

```
用户查询
    ↓
CoT分类引擎
    ↓
┌────────────────────────────────────────────────────────┐
│ 分析步骤:                                              │
│ 1. Query Analysis - 分析查询内容和意图                 │
│ 2. Complexity Assessment - 评估复杂度                  │
│ 3. Keywords Identification - 识别关键词               │
│ 4. Method Selection - 选择处理方法                    │
└────────────────────────────────────────────────────────┘
    ↓
分发到对应处理器
    ↓
┌──────────┬──────────┬──────────┬──────────┐
│  LOCAL   │  GLOBAL  │REASONING │  DRIFT   │
│ 局部查询  │ 全局查询  │ 图推理   │ 漂移搜索  │
├──────────┼──────────┼──────────┼──────────┤
│特定实体   │ 摘要概览  │多跳推理  │ 上下文   │
│属性查询   │ 问题     │关系发现  │ 扩展查询  │
└──────────┴──────────┴──────────┴──────────┘
```

### 3. 四种查询模式详解

> **⚠️ 重要提示**: 所有查询都应通过 `router_qwen.py` 进入，由路由器智能分发到对应处理器。  
> **不建议直接调用** `local_query_qwen.py`、`global_query_qwen.py`、`reasoning_query_qwen.py` 等单独模块。

```bash
# ✅ 推荐使用方式
python core/query_qwen/router_qwen.py

# ❌ 不推荐直接调用
python core/query_qwen/local_query_qwen.py  # 不推荐
```

**路由器工作原理**:
- 使用 CoT (Chain of Thought) 技术分析查询意图
- 自动识别查询类型并选择最优处理器
- 支持四种查询模式：LOCAL、GLOBAL、REASONING、DRIFT

#### GLOBAL (全局查询)

**适用场景**: 摘要、概览、总结类查询  
**示例**: "总结超合金的主要应用领域"  
**触发关键词**: "总结"、"概述"、"主要应用"、"领域"

**核心步骤**:
1. 查询向量化 → 检索 Top-K 相关社区
2. **Map 阶段**: 并行处理每个社区，提取关键点（带引用）
3. **Reduce 阶段**: 聚合所有关键点，生成综合答案

## 🔧 配置说明

主配置文件 `config/settings.yaml` 包含以下部分：

```yaml
# LLM API 配置
api:
  qwen:
    base_url: "..."
    api_key: "..."
    model: "qwen-plus"
  gemini:
    api_key: "..."

# 索引流水线配置
pipeline:
  chunk_size: 1000          # 文本块大小
  chunk_overlap: 200        # 块重叠
  batch_size: 10            # LLM批处理大小

# 图谱构建配置
graph:
  similarity_threshold: 0.85 # 实体消歧阈值
  min_community_size: 3      # 最小社区大小

# 向量化配置
embedding:
  model: "text-embedding-v3"
  dimension: 256

# 查询配置
query:
  local_top_k: 10           # 局部检索数量
  global_top_communities: 3  # 全局检索社区数
  k_hop: 1                  # K-hop邻域扩展

# 图推理配置
reasoning:
  model:
    hidden_dim: 256
    num_layers: 3
    num_heads: 4
  training:
    num_epochs: 100
    learning_rate: 0.001
  inference:
    ppr_alpha: 0.15
    max_path_length: 3
```
