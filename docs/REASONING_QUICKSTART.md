# Graph Reasoning System - Quick Start Guide

## Overview

This guide will help you get started with the graph reasoning system for knowledge graph-based question answering.

## Prerequisites

1. **Data Files Ready**:
   - `data/graphs/final_graph.json` - Knowledge graph structure
   - `data/embeddings/embedding.db/` - LanceDB with entity and relationship embeddings

2. **Environment Setup**:
   ```bash
   # Install required packages
   pip install torch networkx lancedb numpy pandas pyyaml openai
   
   # Set API key (for query encoding and answer generation)
   export QWEN_API_KEY="your-api-key-here"
   ```

3. **Configuration**: The system is pre-configured in `config/settings.yaml` under the `reasoning` section.

## Quick Start

### Step 1: Train the Model (First Time Only)

Train the graph reasoning model using self-supervised learning:

```bash
cd D:\Pycharm\Projects\SuperalloyKgRAG

# Basic training (CPU)
python core/reasoning/train_reasoning.py --epochs 50 --device cpu

# GPU training (recommended if available)
python core/reasoning/train_reasoning.py --epochs 100 --device cuda
```

**Training time**: 
- CPU: ~30-60 minutes for 50 epochs (depending on graph size)
- GPU: ~5-10 minutes for 100 epochs

**What happens during training**:
- Link prediction: Learns to reconstruct graph edges
- Contrastive learning: Learns robust node representations
- Pseudo query matching: Learns query-entity similarity

**Output**: Trained model saved to `data/reasoning/model.pt`

### Step 2: Run Queries

Once the model is trained, you can query the knowledge graph:

```bash
# Basic query
python core/reasoning/run_reasoning_query.py --query "What is the relationship between nickel-based superalloys and turbine blades?"

# Save results to file
python core/reasoning/run_reasoning_query.py \
    --query "How does temperature affect creep resistance?" \
    --output data/reasoning/results.json

# Use different reasoning method
python core/reasoning/run_reasoning_query.py \
    --query "What are the properties of Inconel 718?" \
    --method ppr
```

### Step 3: Interpret Results

The system outputs:

1. **Top Relevant Entities**: Most relevant nodes from the knowledge graph
2. **Reasoning Paths**: Multi-hop paths showing how entities are connected
3. **Final Answer**: Natural language answer generated by LLM based on paths

## Python API Usage

For programmatic access:

```python
from core.query_qwen.reasoning_query_qwen import ReasoningQueryHandler, load_config, setup_logging

# Setup
config = load_config()
setup_logging(config)

# Create handler (loads trained model automatically)
handler = ReasoningQueryHandler(config, load_trained_model=True)

# Run query
results = handler.query(
    query_text="What materials are used in jet engines?",
    method='ppr',  # or 'gnn'
    include_llm_answer=True
)

# Access results
print(f"Found {len(results['top_nodes'])} relevant entities")
print(f"Extracted {results['num_paths']} reasoning paths")

for node in results['top_nodes'][:5]:
    print(f"  - {node['name']}: {node['score']:.4f}")

for i, path in enumerate(results['paths'][:3], 1):
    print(f"\nPath {i}:")
    print(path['explanation'])

if 'answer' in results:
    print(f"\nAnswer: {results['answer']}")
```

## Training from Scratch

If you want to train with custom parameters:

```python
from core.query_qwen.reasoning_query_qwen import ReasoningQueryHandler, load_config, setup_logging

config = load_config()
setup_logging(config)

# Create handler in training mode
handler = ReasoningQueryHandler(config, load_trained_model=False)

# Train
history = handler.train(num_epochs=100)

# The model is now ready for inference
results = handler.query("Your question here", method='ppr')
```

## Configuration Options

Key settings in `config/settings.yaml`:

```yaml
reasoning:
  model:
    hidden_dim: 256        # GNN hidden dimension
    num_layers: 3          # Number of GNN layers
    num_heads: 4           # Attention heads
    use_edge_weights: true # Use composite_importance
  
  training:
    num_epochs: 100
    learning_rate: 0.001
    batch_size: 512
    
  inference:
    top_k_nodes: 20        # Top entities to retrieve
    ppr_alpha: 0.15        # PPR restart probability
    max_path_length: 3     # Maximum path hops
    max_paths_per_query: 10 # Paths to return
```


## Performance Expectations

**Graph Size**: ~10,000 nodes, ~50,000 edges
- Training: 50 epochs in ~10 min (GPU) or ~30 min (CPU)
- Inference: <1 second per query (GPU) or 2-3 seconds (CPU)

**Larger Graphs**: ~100,000 nodes, ~500,000 edges
- Training: May require 1-2 hours even on GPU
- Consider edge sampling during training
- Inference remains fast with proper indexing
